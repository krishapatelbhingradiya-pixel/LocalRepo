Power Query is used in Microsoft Fabric to clean, transform, and prepare raw data for analysis. In this project, Power Query helps us remove duplicate records, handle missing values, rename columns, change data types, filter rows, and maintain data quality. The employee data is transformed using Dataflow Gen2 and loaded into the required destination for further processing. This ensures that the data is clean, consistent, and ready for reporting and analysis. The transformed data is then used in the HR Analytics project to build semantic models and power BI dashboards for analyzing employee information, department-wise distribution, salary details, and other HR metrics.
